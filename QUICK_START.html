🎨 Cara Customize

1. Mengubah Warna

Edit style/landing.css di bagian `:root`:

:root {
  --primary-color: #10b981;      /* Warna Emerald */
  --secondary-color: #06b6d4;    /* Warna Cyan */
  --dark-bg: #0f172a;            /* Background */
  --card-bg: #1e293b;            /* Card background */
}

2. Mengubah Animasi Timing

Edit js/landing-animations.js:

gsap.to(element, {
  duration: 0.8,    // Ubah durasi
  ease: 'power3.out' // Ubah timing
});

3. Menambah Konten

Edit landing_page.php dan gunakan class yang sesuai:

  • • feature-card untuk features
  • • service-item untuk services
  • • pricing-card untuk pricing
  • • testimonial untuk testimonials
  • • faq-item untuk FAQ

🔧 Troubleshooting

❌ Animasi tidak berjalan?

✓ Buka browser console (F12) dan cek apakah ada error

✓ Pastikan GSAP library sudah loaded di CDN

✓ Refresh page dengan Ctrl+F5

❌ Styling tidak muncul?

✓ Pastikan Tailwind CSS CDN terbuka dengan benar

✓ Cek apakah landing.css ter-load di inspector

✓ Bersihkan cache browser

❌ Halaman blank?

✓ Cek apakah path di header.php sudah benar

✓ Lihat PHP errors di Apache error log

✓ Pastikan index.php redirect ke landing_page.php
